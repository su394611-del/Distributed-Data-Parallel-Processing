Distributed LLM Training with PyTorch DDP

An educational AI engineering project demonstrating distributed Transformer training, data parallelism and Qwen2.5 LoRA fine-tuning.

Project Features

  • PyTorch DistributedDataParallel (DDP)
  • Distributed training with torchrun
  • Multi-process training architecture
  • CPU and CUDA execution modes
  • Gloo and NCCL communication backends
  • Gradient synchronization with AllReduce
  • DistributedSampler for data partitioning
  • Custom causal Transformer implementation
  • Multi-GPU data parallelism
  • Qwen2.5-0.5B-Instruct fine-tuning
  • Low-Rank Adaptation (LoRA)
  • Hugging Face Transformers and PEFT
  • Model checkpoint and adapter saving
  • Custom training corpus support
  • Python and Jupyter Notebook examples

Distributed Training Architecture

PyTorch torchrun launches multiple worker processes. Each process maintains a model replica and processes a partition of the training data. DDP synchronizes gradients across workers before optimizer updates.

Tiny Transformer Training

The project includes a small causal Transformer implemented in PyTorch for educational training experiments. CPU demonstrations support multiple processes with the Gloo backend.

Qwen2.5 LoRA Fine-Tuning

A separate training mode demonstrates parameter-efficient fine-tuning using Qwen2.5-0.5B-Instruct and LoRA adapters.

Multi-GPU Training

DDP maintains a separate model replica on each GPU and synchronizes gradients. GPU memory is not pooled across devices.

Validation and Limitations

The small Transformer CPU demonstrations have been tested. Physical multi-GPU training and Qwen CUDA performance are not established benchmarks.
