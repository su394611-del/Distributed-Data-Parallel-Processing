Distributed Data Parallel LLM Training

Distributed language model training using PyTorch DistributedDataParallel (DDP), Transformers and Qwen LoRA.

Project Features

  • Multi-process DDP training
  • Gradient synchronization with AllReduce
  • Custom causal Transformer model
  • Qwen2.5 LoRA fine-tuning
  • CPU and CUDA training modes
